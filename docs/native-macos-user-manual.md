# CowAgent 原生 macOS 用户操作手册

> 适用对象：在 `steven` 用户的 macOS 上直接使用本机 CowAgent 的人。
>
> 本次安装不使用 Docker 或 Kubernetes。CowAgent 由当前用户的 `launchd` 任务常驻运行，Web 控制台仅监听本机地址，个人微信通过官方 iLink 通道接入。

## 1. 快速开始

### 1.1 打开 Web 控制台

在 Mac 上打开浏览器，访问：

```text
http://127.0.0.1:9899/
```

该地址只能在当前 Mac 上访问，局域网或公网中的其他设备不能直接连接。

### 1.2 查看登录密码

首次访问需要输入 Web 访问密码。需要重新查看时，在终端运行：

```bash
jq -r '.web_password' ~/.cow/config.json
```

密码保存在 `~/.cow/config.json`，该文件权限为 `600`。不要把密码、API Key 或微信凭证发到公开聊天、截图或代码仓库。

### 1.3 登录

在登录页输入密码。登录状态默认保持 30 天，重启 CowAgent 后通常不需要重新登录。

右上角退出按钮可以注销当前浏览器会话。修改密码可在 Web 控制台的「配置 → 基础配置 → 安全设置」中完成。

### 1.4 登录后先检查三件事

1. 确认能进入「对话」页面。
2. 在「配置 → 基础配置 → 模型配置」中确认模型厂商、模型和 API Key 已配置。
3. 在「通道」页面确认 `web` 与 `weixin` 的状态符合预期。

安装完成时，默认模型通常是 `deepseek-flash`，但 API Key 为空。未配置 Key 时，控制台仍能登录和管理，但真实对话不能正常工作。

## 2. 首次配置模型

### 2.1 配置主对话模型

1. 打开左侧「配置」。
2. 进入「基础配置」中的「模型配置」卡片；需要更细粒度管理时，也可进入「模型配置」标签页。
3. 选择「模型厂商」，例如 DeepSeek、OpenAI、Claude、Gemini、通义千问或 Kimi。
4. 选择对应的「模型」。
5. 填入该厂商平台创建的 API Key。
6. 使用厂商官方接口时，通常不需要改 API Base；使用第三方代理或 OpenAI 兼容服务时，再按服务商说明填写。
7. 点击「保存」。

保存后先新建一个对话，发送下面的测试消息：

```text
请用一句话确认你已经可以正常对话，并告诉我你当前使用的模型名称。
```

如果提示模型未配置、鉴权失败、余额不足或请求超时，先检查 API Key、API Base、账户余额和厂商服务状态，再到「监控 → 日志」或本机日志中查看错误。

### 2.2 配置其他能力

「模型配置」标签页可以分别管理视觉识别、图像生成、语音识别、语音合成、向量和网络搜索等能力。它们不必和主对话模型来自同一厂商。

建议先只配置主对话模型，确认文字对话可用后，再按需增加其他能力。每增加一项就单独测试，便于定位问题。

### 2.3 深度思考与推理强度

「配置 → 基础配置 → Agent 配置」中可以调整：

- 「深度思考」：开启后，支持的模型会先推理再回答，质量可能更高，但速度更慢、Token 消耗更多。
- 「思考强度」：在开启深度思考后决定推理强度；日常任务通常使用默认值即可。
- 「最大上下文 Token」「最大记忆轮次」「最大执行步数」：决定单次任务可使用的上下文、历史轮次和工具调用次数。

不确定时保留安装默认值，遇到上下文不足或 Agent 提前停止时再调整。

## 3. 使用 Web 对话

### 3.1 新建对话和历史会话

- 点击会话列表顶部的「新对话」，或输入区的 `+`，创建新会话。
- 左侧历史列表保存过往会话，可以继续打开、重命名或删除。
- 删除会话会永久删除该会话及其消息，删除前会要求确认。
- 输入区下方的「工作空间」「本次会话模型」「本次会话权限」只影响当前会话；未单独设置时跟随全局默认。

### 3.2 发送消息和附件

直接在输入框描述任务即可。Agent 会规划步骤，并可能调用文件、终端、浏览器、记忆、知识库、技能或联网搜索等工具。

可以上传文件或文件夹，也可以让 Agent 读取工作空间中的文件。Web 上传总大小上限为 512 MB；更大的文件建议先放到工作空间，再让 Agent 分段处理。

回复生成过程中可以使用「停止」中止当前任务。长任务建议先说明目标、约束、交付格式和验收标准。

### 3.3 清除与压缩上下文

- 「清除上下文」会在当前会话插入分隔线。分隔线以上的消息仍可见，但不再作为模型上下文输入。
- 上下文接近上限时，可以使用「压缩」让 Agent 总结较早对话，释放空间。
- 想彻底开始新任务时，优先使用「新对话」，避免旧任务的历史干扰。

### 3.4 权限模式

当前安装的默认权限是「全部可访问（full-access）」。Agent 可以读取和修改当前 macOS 账户可访问的大部分文件和网络资源。

每个会话可以单独切换为：

| 权限 | 能力 |
| --- | --- |
| 只读 | 只能查看和分析，不修改文件 |
| 工作区可写 | 可在当前工作空间内读写，工作空间外的写入会被拒绝 |
| 全部可访问 | 不加额外限制，可操作当前账户可访问的文件和命令 |

处理不熟悉的代码、下载的脚本或高风险系统操作时，建议临时使用「只读」或「工作区可写」，确认任务范围后再提高权限。

### 3.5 查看结果与产物

Agent 生成的文件通常保存在当前工作空间。Web 控制台的「工作空间」面板可以浏览、预览、下载或编辑文件。

如果菜单中启用了「产物」，网页、图片、音视频和文档会按时间汇集在「监控 → 产物」中。产物页只负责展示和索引，原文件仍以工作空间中的实际文件为准。

### 3.6 提问示例

```text
查看工作空间里有哪些文件，按类型整理后给我一份清单。
```

```text
读取 ~/cow 下的需求文档，生成一份中文技术方案，写入 Markdown 文件并告诉我路径。
```

```text
打开这个网页并提取正文要点。先不要提交表单，也不要下载可执行文件。
```

```text
检查当前目录的 Python 项目，运行最相关的测试；失败时只修复与本次任务相关的问题。
```

涉及付款、删除、覆盖、发布、发送给他人或修改系统配置的操作，应在提示中写清边界，并要求 Agent 操作前确认。

## 4. 使用个人微信

### 4.1 扫码接入

1. 打开 Web 控制台左侧「通道」。
2. 点击「接入通道」。
3. 选择「微信」，再点击「接入」。
4. 页面显示二维码后，使用微信扫描并在手机上确认。
5. 等待页面显示登录成功和通道已接入。

微信客户端建议使用 8.0.69 或更高版本。二维码约 2 分钟过期，页面会自动刷新；如果一直停留在等待状态，可以重新打开二维码或重启服务后再试。

### 4.2 对话方式

登录后，微信中会出现机器人助手，通常名为「微信ClawBot」。你可以改备注、头像或置顶，不影响 CowAgent 运行。

支持私聊文本、图片、文件、视频等消息。语音消息能否识别取决于语音识别模型是否配置成功；未配置时可能只收到文件或提示识别失败。

首次验收建议发送：

```text
你好，请回复“微信通道正常”，并告诉我现在可以帮你做什么。
```

### 4.3 24 小时主动消息限制

受微信平台限制，机器人只能在用户最近一次发消息后的 24 小时内主动推送消息。超过 24 小时后，定时任务或主动提醒可能发送失败；用户在微信中发送任意消息后即可恢复。

### 4.4 重新登录与状态恢复

- 微信 session 过期后，CowAgent 通常会清除旧凭证并重新生成二维码。
- 如果控制台显示未接入或长期没有二维码，可先重启服务，再回到「通道」页面重新接入。
- 微信登录凭证保存在 `~/.cow/weixin_credentials.json`，文件权限应保持 `600`。
- 恢复旧备份后通常需要重新扫码，因为个人微信登录凭证不在备份归档中。

## 5. 工作空间与数据位置

### 5.1 主要路径

| 路径 | 用途 | 权限 |
| --- | --- | --- |
| `~/cow` | Agent 默认工作空间、记忆、知识、技能、会话产物 | `700` |
| `~/.cow` | 数据根，保存配置、登录凭证和浏览器缓存 | `700` |
| `~/.cow/config.json` | 主配置、模型 Key、Web 密码等 | `600` |
| `~/.cow/weixin_credentials.json` | 微信登录凭证（登录成功后生成） | `600` |
| `~/.cow/ms-playwright` | Playwright Chromium 浏览器缓存 | 仅当前用户 |
| `~/Backups/CowAgent` | 自动和手动备份 | `700` |
| `~/Library/Logs/CowAgent` | 服务和维护任务日志 | `700` |

### 5.2 `~/cow` 中常见内容

```text
~/cow/
├── SYSTEM.md       # Agent 系统提示词
├── USER.md         # 用户资料
├── MEMORY.md       # 核心记忆
├── memory/         # 每日记忆
├── knowledge/      # 个人知识库
├── skills/         # 自定义技能
└── agents/         # 多 Agent 配置和各自工作空间
```

具体文件会随使用情况增加。重要资料可以继续放在 `~/cow` 或单独项目目录中；删除或移动文件前先确认是否被 Agent 或知识库引用。

### 5.3 项目工作空间

除了默认 `~/cow`，每个会话还可以绑定一个项目目录。绑定后，Agent 的文件读写和命令执行优先在该项目内进行，而记忆、技能等仍保存在默认工作空间。

适合为不同代码仓库、写作项目或资料目录建立独立工作空间，减少不同任务之间的文件干扰。

## 6. 日常运行与维护

### 6.1 服务状态

```bash
launchctl print gui/$(id -u)/com.steven.cowagent
```

重点查看 `state = running` 和 `pid`。健康检查：

```bash
curl -sS http://127.0.0.1:9899/api/health
```

正常返回：

```json
{"status":"ok"}
```

### 6.2 重启服务

```bash
launchctl kickstart -k gui/$(id -u)/com.steven.cowagent
```

重启不会自动打开浏览器。登录会话、配置、微信凭证和工作空间数据会保留。

### 6.3 临时停止与恢复启动

临时停止：

```bash
launchctl bootout gui/$(id -u)/com.steven.cowagent
```

重新加载：

```bash
launchctl bootstrap gui/$(id -u) "$HOME/Library/LaunchAgents/com.steven.cowagent.plist"
launchctl kickstart -k gui/$(id -u)/com.steven.cowagent
```

不要使用 `cow start`、`cow stop` 或 Web 控制台的一键更新管理本安装，否则可能与 `launchd` 的状态冲突。

### 6.4 查看日志

```bash
tail -f ~/Library/Logs/CowAgent/service.out.log
tail -f ~/Library/Logs/CowAgent/service.err.log
```

Web 控制台的「监控 → 日志」也可以查看运行日志。排查问题时，先记录报错时间，再对照对应时间段的日志。

### 6.5 升级

```bash
cd /Users/steven/CowAgent
bash scripts/update-native-macos.sh
```

脚本会停止服务、执行 fast-forward 更新、更新依赖并重启；失败时会恢复更新前的 commit 并尝试恢复旧版本服务。升级前建议先做一次手动备份。

不要点击 Web 控制台的版本更新按钮，也不要直接运行 `cow update`。

## 7. 备份与恢复

### 7.1 自动备份

备份任务 `com.steven.cowagent.backup` 每天 `03:00` 运行：

- 备份位置：`~/Backups/CowAgent/`
- 文件名：`cowagent-YYYYMMDD-HHMMSS.zip`
- 保留最近 7 份
- 归档权限：`600`
- 单份归档不加密

每日维护时会检查日志；单个日志超过 20 MB 时压缩轮转，保留最近 5 份。

### 7.2 立即备份

```bash
cd /Users/steven/CowAgent
bash scripts/cowagent-maintenance.sh
```

归档通常包含配置、Agent 人格文件、记忆、会话历史、知识库、自定义技能、定时任务和多 Agent 工作区。临时文件、浏览器缓存、Git 元数据和符号链接不进入归档。

备份可能包含 API Key、Web 密码、个人对话和文件内容，务必按敏感数据保管。个人微信登录凭证不在归档中，恢复后通常需要重新扫码。

### 7.3 恢复某个备份

先停止服务，再恢复：

```bash
launchctl bootout gui/$(id -u)/com.steven.cowagent
cd /Users/steven/CowAgent
COW_DATA_DIR="$HOME/.cow" .venv/bin/cow restore \
  "$HOME/Backups/CowAgent/cowagent-YYYYMMDD-HHMMSS.zip" \
  --workspace "$HOME/cow"
```

恢复命令会校验归档并覆盖同名文件，不会删除目标目录中的其他文件；如检测到现有数据，还会先生成一份 `cow-pre-restore-*.zip` 回滚备份。恢复完成后重新加载服务：

```bash
launchctl bootstrap gui/$(id -u) "$HOME/Library/LaunchAgents/com.steven.cowagent.plist"
launchctl kickstart -k gui/$(id -u)/com.steven.cowagent
curl -sS http://127.0.0.1:9899/api/health
```

恢复后检查模型配置、工作空间文件、Web 登录和微信通道。微信一般需要重新扫码。

## 8. 常见问题

| 现象 | 先检查 | 处理 |
| --- | --- | --- |
| 浏览器打不开控制台 | 服务是否运行、端口是否监听 | 运行 `launchctl print gui/$(id -u)/com.steven.cowagent`；必要时重启服务 |
| 页面能打开但密码错误 | 是否复制了完整密码 | 运行 `jq -r '.web_password' ~/.cow/config.json` 后重新输入 |
| 对话提示模型未配置 | 模型厂商、模型名、API Key、余额 | 在「配置 → 模型配置」重新保存并新建对话测试 |
| 模型请求超时或鉴权失败 | API Base、代理、厂商状态、日志 | 恢复官方 API Base，检查 Key 是否过期或被禁用 |
| 微信二维码过期 | 页面是否自动刷新 | 重新打开「通道 → 微信」获取新二维码；仍失败时重启服务 |
| 微信已扫码但没有回复 | 通道状态、服务状态、模型配置 | 先看「通道」再查日志；确认模型已配置 |
| 微信定时推送失败 | 距离用户上次发消息是否超过 24 小时 | 让用户在微信中发一条消息后再试 |
| 语音识别不可用 | 语音识别模型和 API Key | 在「模型配置」中配置语音识别；讯飞星火语音暂不支持 |
| 浏览器工具失败 | `~/.cow/ms-playwright` 是否存在 | 重启服务；仍失败时重新执行安装脚本 |
| 服务反复退出 | 日志中的启动异常 | 查看 `service.err.log`，修复配置或依赖后再启动 |
| 升级失败 | 更新脚本输出和日志 | 脚本会尝试回退；保留报错信息，不要连续盲目重试 |
| 磁盘空间持续减少 | 备份、日志、工作空间产物 | 检查 `~/Backups/CowAgent`、`~/Library/Logs/CowAgent` 和 `~/cow` |

## 9. 安全与使用边界

- **Full Access 风险**：Agent 当前可访问该 macOS 账户的大部分文件、终端和网络资源。只让它执行你理解并信任的任务。
- **仅本机监听**：Web 控制台绑定 `127.0.0.1:9899`。不要把监听地址随意改成 `0.0.0.0`；如确需远程访问，应同时启用强密码、防火墙和可信网络。
- **敏感数据**：配置、日志、备份和会话记录可能包含 API Key、密码和个人资料，不要上传到公开网盘或 Git。
- **系统睡眠**：Mac 睡眠时服务离线，唤醒后由 `launchd` 恢复；不保证睡眠期间执行定时任务。
- **登录时机**：这是用户级 LaunchAgent，macOS 用户登录后启动，不是开机登录前就以系统服务运行。
- **微信限制**：支持个人微信私聊，但受微信平台 24 小时主动消息限制；账号状态和平台规则仍由微信控制。
- **语音限制**：讯飞星火语音因 `websocket-client` 版本冲突未启用；其他语音能力取决于已配置的语音厂商和模型。
- **备份不加密**：ZIP 归档便于恢复，但不是加密保险箱，应按敏感文件管理。
